# LION currentness/evidence identity model

Status: CURRENT_STANDARD. Authority effect: NONE.

Different Git identities can be simultaneously valid only when their evidence type is explicit.

- LIVE_REPOSITORY_OBSERVATION — freshly reacquired default-branch HEAD/TREE for the claim being made.
- EPOCH_CURRENTNESS_CARRIER — immutable carrier for a stabilized architecture/currentness epoch.
- SOURCE_BOUND_PROJECTION — deterministic projection bound to explicit source identities.
- CANDIDATE_BINDING — pre-integration candidate identity used by formalization/verification.
- HISTORICAL_EVIDENCE — immutable evidence of a past event or epoch.

Stored snapshots are not self-refreshing live truth. Historical carriers are not rewritten to later HEADs. A current claim must reacquire the evidence plane relevant to that claim.
