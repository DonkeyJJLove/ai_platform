# LION standards

This directory contains current, machine-testable conventions for the LION federation.

Read order:

1. LION_NAMING_STANDARD.md / .json
2. LION_STATUS_MODEL.md / .json
3. LION_VERSION_MODEL.md / .json
4. LION_REPOSITORY_LAYOUT_STANDARD.md / .json
5. LION_CURRENTNESS_EVIDENCE_MODEL.md / .json
6. LION_GENERATED_OUTPUT_POLICY.md / .json

These standards do not rewrite immutable historical evidence and do not grant runtime or merge authority.

CURRENT CANONICAL NAME != HISTORICAL NAME
LIFECYCLE != CURRENTNESS != AUTHORITY != EXECUTION != VERIFICATION != DEPLOYMENT
ARCHITECTURE EPOCH != PRODUCT RELEASE != CONTRACT VERSION != FORMALIZATION REVISION
LIVE OBSERVATION != EPOCH CARRIER != SOURCE-BOUND PROJECTION
