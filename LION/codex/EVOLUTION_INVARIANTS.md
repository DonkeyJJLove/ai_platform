# Inwarianty ewolucji

Każdy identyfikator jest kontraktem procesu, nie nowym uprawnieniem. Dla naruszenia zachowaj kontrprzykład, sklasyfikuj dotknięte dowody i zatrzymaj wyłącznie zależne działanie.

- `I01_CAPABILITY_GROWTH_DOES_NOT_IMPLY_AUTHORITY_GROWTH`
- `I02_MODEL_OUTPUT_IS_NOT_VERIFIED_ARTIFACT`
- `I03_REPRESENTATION_IS_NOT_PROPOSAL`
- `I04_PROPOSAL_IS_NOT_AUTHORITY`
- `I05_PDP_ALLOW_IS_NOT_RUNTIME_ADMISSION`
- `I06_RUNTIME_ADMISSION_IS_NOT_EFFECT`
- `I07_EFFECT_RECEIPT_IS_NOT_OBSERVATION`
- `I08_OBSERVATION_IS_NOT_RECONCILIATION`
- `I09_COMMIT_IS_NOT_INTEGRATION`
- `I10_MERGE_IS_NOT_DEPLOYMENT`
- `I11_HISTORICAL_CURRENT_IS_NOT_LIVE_CURRENT`
- `I12_NEW_HEAD_INVALIDATES_OLD_HEAD_BOUND_EVIDENCE`
- `I13_UNKNOWN_NEVER_PROMOTES_TO_PASS`
- `I14_BUILDER_IS_NOT_INDEPENDENT_VERIFIER`
- `I15_CAPABILITY_IS_NOT_AUTHORITY`
- `I16_NON_CARRIER_SOURCE_STABILIZES_BEFORE_CARRIER_REBIND`
- `I17_SECURITY_SOURCE_STABILIZES_BEFORE_SCAN_REFREEZE`
- `I18_CARRIER_REBIND_IS_LAST_SEMANTIC_WRITE_OF_CURRENTNESS_EPOCH`
- `I19_NO_SELF_REFERENTIAL_CURRENTNESS`
- `I20_NO_FALSE_COMPLETION`
- `I21_NO_LAST_WRITER_WINS_SEMANTICS`
- `I22_ONE_ROOT_CAUSE_SHOULD_NOT_BE_PATCHED_AS_MANY_CASCADE_FAILURES`
- `I23_EFFECT_SUCCESS_REQUIRES_POSTCONDITION_EVIDENCE`
- `I24_RETRY_OF_NON_IDEMPOTENT_EFFECT_REQUIRES_RECONCILIATION`
- `I25_MODEL_SUCCESSION_MUST_NOT_REQUIRE_HIDDEN_REASONING`

I14 dotyczy deklarowania niezależności: lokalny self-test może być użyteczny, lecz nie jest niezależnym przeglądem. I19 zabrania wiązania dokumentu z jego własnym przyszłym hashem; instancje obserwacji i jawne domeny wykluczeń rozwiązują ten problem. I25 wymaga przekazania weryfikowalnych wniosków, nie prywatnego procesu rozumowania.
