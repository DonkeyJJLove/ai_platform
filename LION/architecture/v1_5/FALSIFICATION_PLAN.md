# Federated architecture knowledge falsification plan

The candidate fails if any of the following is observed:

1. more than one primary semantic owner for a required concept;
2. a peer dependency or role change can leave global architecture projection `CURRENT`;
3. a required peer is `UNKNOWN` while federated formalization closes `PASS`;
4. human architecture prose contradicts a machine contract without a failing test;
5. a stale HEAD/TREE remains document-current;
6. a fresh agent cannot reach the global owner within the declared read bound;
7. repository manifest role and global registry role diverge silently;
8. `TARGET_ONLY` receives implementation evidence;
9. versioned RAG is interpreted as live truth;
10. `VALIDATE_ONLY` or `NOT_APPLICABLE` repositories are mutated by formalization;
11. architecture documentation or formalization mints authority;
12. federation vector or truth carrier self-references its final identity;
13. a non-carrier semantic write occurs after carrier-last closure.
